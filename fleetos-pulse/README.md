# FleetOS Pulse — React Frontend Dashboard

This directory contains the Vite + React + TypeScript frontend dashboard for FleetOS Pulse.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run test suite
npm test

# Production build
npm run build
```

## Environment Configuration

Copy `.env.example` to `.env`:
```env
VITE_API_BASE_URL=http://localhost:8000
```

Refer to the main project [`DEPLOYMENT.md`](../DEPLOYMENT.md) for full cloud deployment instructions.
